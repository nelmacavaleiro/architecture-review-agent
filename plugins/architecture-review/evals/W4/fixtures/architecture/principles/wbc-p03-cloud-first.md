## WBC-P03 Cloud first, with AWS as the standard platform

Type: Guidance
Statement: New services use cloud services, hosted on AWS unless a software-as-a-service product is a better fit.
Rationale: Follows the Government's Cloud First policy, and lets the council close its server room when the remaining contracts end.
Implications: Proposals should not add new equipment to the server room. Hosted services should use the AWS London region (see ADR-0001).
Exceptions: Discussed at the Digital Design Authority.
