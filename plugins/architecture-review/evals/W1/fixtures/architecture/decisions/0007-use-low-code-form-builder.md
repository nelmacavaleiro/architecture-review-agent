# ADR-0007 Use a low-code form builder for resident forms

Status: Deprecated
Date: 2023-06-05
Context: Services needed a quick way to put simple forms online.
Decision: Simple resident forms are built with the council's low-code form builder.
Consequences: Forms could be built quickly by service teams. This decision was deprecated in October 2025 when the form builder contract was not renewed. No replacement has been agreed yet.
