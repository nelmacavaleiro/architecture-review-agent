# ADR-0001 Use AWS in the London region for hosted services

Status: Accepted
Date: 2023-09-18
Context: The council was hosting services in its own server room and with several small hosting suppliers, with uneven security and support.
Decision: New hosted services run on AWS in the London region (eu-west-2). Other regions need an approved exception.
Consequences: One platform to secure and support. Staff need AWS skills, and costs must be monitored monthly because they vary with use.
