# ADR-0002 Use Microsoft 365 and Entra ID for staff

Status: Accepted
Date: 2023-11-06
Context: Staff used separate logins for email, file storage and many business systems.
Decision: Staff use Microsoft 365 for email, documents and collaboration, and sign in to business systems through Microsoft Entra ID with multi-factor authentication wherever the system supports it.
Consequences: One login for most staff tasks, and leavers can be removed in one place. Systems that cannot use Entra ID keep separate accounts and must be reviewed every quarter.
