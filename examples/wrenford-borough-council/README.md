# Wrenford Borough Council (fictional)

Wrenford Borough Council is a fictional English borough council created to test the architecture review agent. It does not represent any real organisation.

## Context

- Provides council tax collection, housing, waste and recycling, planning, and other services to residents and local businesses.
- Works under a fixed budget, with value for money scrutinised by councillors and the public.
- Hosts new services on Amazon Web Services (AWS) in the London region, and uses Microsoft 365 for staff.
- Still runs an older housing case management system in its own server room, under a contract that ends in 2028.
- Main architecture concerns: accessibility, protecting residents' personal data, open standards, reuse of shared public sector services, and value for money.
